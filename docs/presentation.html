CrisisMesh

Disaster Response Coordination App

🌐 Real-time • 🤖 AI-Powered • ☁️ Serverless on AWS

📚 Cloud Computing (AWS) — November 2026 👤 Student Name  |  🎓 Roll Number

🚨 Problem Statement

  • 🔀 Fragmented coordination — agencies, volunteers, and victims use disconnected channels
  • 🗺️ No centralized geospatial view — incidents scattered across phone calls, texts, social media
  • 📦 Inefficient supply distribution — donations pile up in one area, shortages in another
  • 🏚️ Slow damage assessment — manual inspection takes days, delays relief priority
  • ⏱️ Time kills — in the golden 72 hours, every minute of delay costs lives

💡 Solution Overview

A real-time, map-based platform connecting 3 key stakeholders:

🆘 Victims

  • Report incidents with photos & GPS
  • Request supplies & rescue
  • Track response status

🙋 Volunteers

  • Register skills & availability
  • Offer supply donations
  • Get matched to nearby needs

🎯 Coordinators

  • Command-center dashboard
  • Broadcast emergency alerts
  • AI-powered severity triage

🏗️ System Architecture

Frontend → API Layer → Compute → Data → AI → Messaging

🤖 AI & Hosting & IaC

✨ Key Features

  • 🗺️ Live interactive map — severity-coded markers with real-time incident tracking
  • 📸 AI damage classification — photo upload → Rekognition → auto-severity assignment
  • 🔄 Automated supply matching — SQS pipeline matches requests to nearest volunteer offers
  • 🚨 Emergency alert broadcasting — coordinators push alerts to all users via SNS
  • 👥 Role-based access control — Victim, Volunteer, Coordinator with scoped permissions
  • ⚡ Real-time updates — GraphQL subscriptions push changes instantly to all connected clients

⚙️ Event-Driven Pipelines

📸 Pipeline 1: AI Damage Assessment

📸 Photo Upload → 🪣 S3 Event → ⚡ Lambda → 🤖 Rekognition → 💾 DynamoDB

Auto-classifies damage severity: Critical / High / Medium / Low

📦 Pipeline 2: Supply Matching

📋 Supply Request → 📬 SQS Queue → ⚡ Lambda → 🔍 Match Nearest → 📢 SNS Notify

Async processing with dead-letter queue for reliability
